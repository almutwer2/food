# شهي — موقع مطعم وطلبات عبر واتساب

موقع عربي باتجاه RTL بهوية مطعم فاخرة: تدرجات نبيذي وإسبريسو، لمسات ذهب معتّق، وخلفيات عاجية. يستخدم Amiri للعناوين وTajawal للنصوص، ومبني بـ HTML وCSS وJavaScript عادي — بلا إطار عمل أو خطوة بناء.

## تشغيل الموقع

افتح مجلد المشروع في الطرفية وشغّل خادمًا محليًا بسيطًا:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

ثم افتح `http://localhost:4173`. ويمكن أيضًا رفع الملفات مباشرة إلى GitHub Pages أو Netlify أو Vercel.

## قبل استقبال طلبات حقيقية

افتح `script.js` وعدّل القيم في أول الملف:

```js
const CONFIG = Object.freeze({
  whatsappNumber: "249XXXXXXXXX", // رمز الدولة ثم الرقم، أرقام فقط
  sanityProjectId: "",            // اتركه فارغًا لاستخدام قائمة العرض
  sanityDataset: "production",
  // ...
});
```

1. استبدل `249XXXXXXXXX` برقم واتساب المطعم الدولي، من دون `+` أو مسافات. لا يفتح الموقع واتساب ما دام الرقم تجريبيًا.
2. حدّث أسماء الأطباق والأسعار والعناوين في `DEMO_PRODUCTS` وبيانات الصفحة بما يناسب المطعم. الأسعار والتوصيل الحالية أمثلة بالـجنيه السوداني، وكذلك التقييمات والآراء ومواعيد العمل — استبدلها بالبيانات الحقيقية قبل الإطلاق.
3. عند استخدام Sanity، أضف معرّف المشروع العام في `sanityProjectId`، واجعل مجموعة البيانات عامة للقراءة، وأضف نطاق الموقع المنشور إلى قائمة CORS في إعدادات المشروع. لا تضع **أي Write/Editor Token** في الواجهة.

### حقول Sanity المتوقعة

- نوع المستند: `product`
- `name` (نص)، `description` (نص)، `price` (رقم)، `badge` (نص اختياري)
- `isAvailable` (منطقي اختياري)، `order` (رقم للترتيب)
- `image` (صورة، مع نص بديل اختياري `alt`)
- `category` مرجع إلى فئة تحتوي `title` و`slug.current`

استخدم قيم slug التالية لظهور الفلاتر العربية الجاهزة: `mains` للأطباق الرئيسية، و`drinks` للمشروبات، و`dessert` للتحلية، و`sides` للمقبلات. عند تفعيل Sanity يجلب الموقع القائمة من **واجهة القراءة العامة**، وإذا تعذّر الاتصال يعرض قائمة العرض المحلية بدلًا منها.

## ما يعمل في الموقع

- البحث في الأطباق وتصفيتها حسب الفئة.
- سلة محفوظة في المتصفح، مع زيادة الكميات أو تقليلها أو حذفها.
- حساب آمن للمبالغ بالسنتات لتجنّب أخطاء الكسور، مع رسم توصيل وخصم الرمز `SHAHI10` (10٪).
- نموذج اسم ورقم وعنوان وملاحظات، ثم إنشاء رسالة طلب عربية مشفّرة وفتحها عبر رابط واتساب الرسمي `wa.me`.
- واجهة متجاوبة، صور حقيقية محلية، خطّا Amiri وTajawal محليان، ودعم لوحة المفاتيح وتقليل الحركة.
